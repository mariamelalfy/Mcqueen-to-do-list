# Lightning McQueen To-Do List

This is a simple command-line to-do list program made in Python. The program helps Mcqueen keep track of the things he needs to do before his next race.

## Features
- Add a new task
- View all tasks
- Mark a task as done
- Remove a task
- Quit the program

## Requirements
- Python 3
- Libraries used: None (only Python built-in features)

## How to Run
1. Make sure Python 3 is installed.
2. Run using the run button inside of vs code.

## Challenges
One challenge was figuring out how to mark a task as completed, I solved it by adding "[Done]" before the task name when the user marks it as completed. Another challenge was making the menu repeat after every action. I solved this by using a `while` loop so the program keeps running until the user chooses to quit. Also, I had some challenges writing code using python since I was not familiar with the syntax.
